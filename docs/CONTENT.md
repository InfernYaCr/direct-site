# CONTENT — инвентарь контента (плейсхолдеры)

> Все строки ниже — **структурные плейсхолдеры**, описывающие *роль* блока, а не
> финальный текст. Реальные тексты/кейсы/изображения пользователь заменит позже,
> редактируя один файл данных `src/content/site.ts`. Контент референса
> не копируется дословно.

Единый источник контента — `src/content/site.ts` (типизированный объект).
Компоненты только рендерят данные оттуда → замена текста = правка одного файла.

## Модель данных (черновик `site.ts`)

```ts
export const site = {
  meta: { title, description, ogImage, lang: 'ru' },
  hero: { brandName, tagline, programPitch, cta: { label, href } },
  bridge: { heading },                              // «Давай по порядку»
  magazine: { heading, body, formCta },             // лид-магнит + email-форма
  donate: { heading, products: Product[] },         // 3 карточки
  club: { heading, body, cta },
  services: { heading, items: Service[] },          // консультация + аудит
  cases: { heading, items: CaseItem[] },            // галерея результатов
  reviews: { heading, items: Review[] },
  channels: { heading, groups: ChannelGroup[] },    // каналы автора / отзывы
  affiliate: { heading, body, cta },
  footer: { email, telegram, policies: Link[], offers: Link[] },
  cookie: { text, accept },
} as const;
```

## Секции и плейсхолдеры

| Секция | Поля-плейсхолдеры | Кол-во элементов |
|---|---|---|
| Hero | имя/бренд, подзаголовок, питч программы, 1 CTA | — |
| Bridge | один заголовок-связка | — |
| Magazine | заголовок, описание лид-магнита, email-форма (заглушка) | — |
| Donate | заголовок + 3 карточки `{title, blurb, cta}` | 3 |
| Club | заголовок, описание, 1 CTA | — |
| Services | заголовок + 2 услуги `{title, desc, formCta}` | 2 |
| Cases | заголовок + сетка карточек `{thumb, result}` | ~12 плейсхолдеров |
| Reviews | заголовок + сетка отзывов `{thumb}` | ~9 плейсхолдеров |
| Channels | 2 группы по N каналов `{title, cta}` | 4 + 3 |
| Affiliate | заголовок, описание условий, 1 CTA | — |
| Footer | email, личный TG, 2 политики, 7 ссылок-оферт | — |
| Cookie | текст согласия + кнопка «Принять» | — |

## Ассеты-плейсхолдеры

- Логотип/портрет: SVG-плейсхолдер `public/placeholder/avatar.svg`.
- Превью продуктов/журнала: генерируемые градиентные плейсхолдеры с подписью.
- Кейсы/отзывы: серые карточки-плейсхолдеры с псевдо-скрином (без чужих картинок).
- Favicon/OG: временные собственные.

## Правило замены контента (для будущего этапа)

1. Открыть `src/content/site.ts`.
2. Заменить строки и пути к ассетам на реальные.
3. Положить ассеты в `src/assets/` (оптимизация через Astro `<Image>`).
4. Вёрстку/компоненты не трогать — они контент-агностичны.
