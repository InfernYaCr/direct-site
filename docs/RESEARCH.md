# RESEARCH — анализ референса nkorytin.ru

> Источник: https://nkorytin.ru/ (получен HTML 2026-05-16). Документ описывает
> структуру и дизайн-систему референса. Тексты/изображения референса трактуются
> как **временные плейсхолдеры** и будут заменены своим контентом.

## 1. Тип ресурса

Длинный продающий лендинг-визитка инфо-эксперта (личный бренд: системные
продажи / запуски / воронки). Одна страница, вертикальный сторителлинг,
много CTA и lead-форм, упор на кейсы и социальное доказательство.

## 2. Технология референса

| Параметр | Значение |
|---|---|
| Платформа | Tilda (визуальный конструктор) |
| Тип блоков | В основном Zero Block (`data-record-type=396`) — пиксельная вёрстка |
| CDN медиа | `*.tildacdn.com` |
| Шрифт | **Qanelas** (геометрический гротеск, **коммерческий/платный**) |
| Анимации | Стандартные Tilda (hover на CTA, появление при скролле); GSAP/AOS/Framer не обнаружены |
| Аналитика | Cookie-баннер присутствует, конкретный счётчик в разметке не виден |

**Вывод:** референс — это не «фреймворк», а экспорт конструктора. Воспроизводим
не код Tilda, а **визуальный результат и структуру** на чистом Astro + TS.

## 3. Дизайн-токены (извлечены из HTML)

```
--color-bg          #ffffff
--color-bg-alt      #f5f5f5
--color-bg-alt-2    #f9f9f9
--color-text        #1c1c1c
--color-text-strong #000000
--color-accent      #eb4100   /* основной CTA */
--color-accent-hover#d1290e   /* hover/active CTA */
--color-accent-2    #ffc029   /* жёлтый акцент */
--color-overlay     rgba(0,0,0,0.30)
```

- Тема: **светлая**, белый фон, чёрный текст, тёплый оранжево-красный акцент.
- Типографика: один геометрический гротеск, крупные заголовки, контраст по
  размеру. Qanelas — платный → **свободная замена: Onest** (variable, есть
  кириллица, лицензия OFL; близок по геометрии). Запасной вариант — Manrope.
- Радиусы/тени: мягкие скруглённые кнопки, лёгкие тени на карточках.

## 4. Карта секций (порядок сверху вниз)

| # | Секция | Назначение | Медиа | Форма |
|---|---|---|---|---|
| 1 | Hero | Заголовок личного бренда + набор в флагман-программу | лого/портрет | — |
| 2 | «Давай по порядку» | Смысловой мост к офферам | — | — |
| 3 | Бесплатный журнал | Лид-магнит: печатный + электронный | обложки | email |
| 4 | Продукты за донат | 3 карточки (контент за донат) | превью ×3 | CTA |
| 5 | Закрытый клуб | Подписное сообщество | баннер | CTA |
| 6 | Услуги | Консультация + аудит | иконки | запись ×2 |
| 7 | Кейсы | Галерея результатов клиентов (~30+ скринов) | много | — |
| 8 | Отзывы о продуктах | Социальное доказательство | скрины | — |
| 9 | Telegram-каналы | Каналы автора + каналы с отзывами | превью | CTA подписки |
| 10 | Партнёрская программа | Реферальная регистрация | баннер | регистрация |

Tilda дробит секции на множество `rec`-блоков; мы объединяем их в **12
логических секций → 12 Astro-компонентов**.

## 5. Что важно повторить (приоритет)

1. Вертикальный ритм и крупная типографика заголовков.
2. Узнаваемые CTA-кнопки (оранжевый акцент, hover-состояние).
3. Карточно-галерейная подача кейсов/отзывов.
4. Чередование фонов (white / light-gray) для разделения секций.
5. Адаптив 320 / 375 / 768 / 1024 / 1440 без переполнения.

## 6. Что НЕ копируем

- Платный шрифт Qanelas (берём Onest).
- Изображения с Tilda CDN (свои плейсхолдеры/оптимизированные ассеты).
- Тексты/бренд Корытина — только структурные подписи-плейсхолдеры.
- JS-рантайм Tilda — пишем своё, near-zero JS.
